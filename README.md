Meu Controle Financeiro 💰
📱 Sobre o projeto
O Meu Controle Financeiro é um aplicativo mobile desenvolvido em Kotlin utilizando o Android Studio, com o objetivo de auxiliar os usuários no gerenciamento de suas finanças pessoais.

O aplicativo permite controlar receitas, despesas, controlar o saldo financeiro e visualizar relatórios de gastos de maneira simples, prática e intuitiva.

O projeto foi desenvolvido com a proposta de um Micro SaaS , utilizando o modelo de negócio Freemium, que oferece funcionalidades gratuitas e uma opção Premium com recursos adicionais.

🎯 Objetivo
Desenvolver uma aplicação móvel funcional para controle financeiro pessoal, aplicando conhecimentos de desenvolvimento Android, armazenamento local, organização de código e conceitos de monetização digital.

💎 Modelo de Negócio
O Meu Controle Financeiro utiliza o modelo Freemium, no qual o usuário pode utilizar gratuitamente as funcionalidades básicas e optar pela assinatura Premium para ter acesso a recursos adicionais.

Esse modelo permite demonstrar conceitos de monetização e escalabilidade de um Micro SaaS.
